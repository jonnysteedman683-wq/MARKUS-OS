Web search unavailable in this runtime, so competitor numbers are from latest cached/eval mirrors; gaps are annotated `[UNVERIFIED]`.

## Tier 1 — Evolution Leaders
1. **Google DeepMind** — biggest model/agent infra; high real-world evolution via search+robotics+model updates, but slower public rollout due to safety reviews.
2. **OpenAI** — fastest commercial model release cadence; broad API + GPT ecosystem; strongest empirical eval coverage.

## Tier 2 — Strong Evolvers
3. **Anthropic** — strong reasoning + code scores; slower cadence than OpenAI but better safety-constrained evals.
4. **Meta (FAIR/Llama)** — fastest open-weight diffusion; huge community evolution rate, less centralized control.
5. **xAI / Tesla** — compute-heavy; real-world fleet data advantages; narrower public agent tooling.
6. **Mistral** — best latency/efficiency curve; strong EU/edge deployment.

## Tier 3 — Niche / Vertical Leaders
7. **Cohere** — enterprise RAG/embedding leader.
8. **Agency/Autonomous-agent startups** — fastest narrow-task evolution.
9. **Nous Research / Hermes ecosystem** — fastest per-user iterative self-evolution in personal workflow; smallest scale.
